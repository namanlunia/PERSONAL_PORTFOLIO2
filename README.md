# Player Profile Portfolio

A fast, responsive single-page personal portfolio website for Naman Lunia designed as a restrained character sheet and quest log HUD. It introduces his foundational computer science background, hands-on IoT work, AI coursework, and dedication to game development.

## Tech Stack

- Semantic HTML5
- CSS3 with CSS Custom Properties (inline, no build step, no frameworks)
- Vanilla JavaScript (no dependencies, no icon library)

## How to Run

Open `index.html` directly in any modern web browser, or serve it with any static web server:

```bash
# Example with Python static server:
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Design Notes

Built with a flat palette of warm charcoal (`#0F1214`), surface (`#161B1E`), line (`#2B3439`), bone text (`#E8E4D8`), muted gray (`#8E9993`), and amber accent (`#E5A03A`), using Chakra Petch for headings and IBM Plex Sans for body typography.
